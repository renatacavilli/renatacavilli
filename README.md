# Renata Cavilli

**AI & Quantitative Researcher at Alpha Options · Mathematics at Universitat de Barcelona**

I work at Alpha Options, where I research and build machine-learning models for financial
time series.

The repositories here are personal projects, separate from that work. I use them to explore
questions in the areas I enjoy most:

- Statistics and econometrics
- Differential equations and dynamical systems
- Numerical methods
- Quantitative finance
- Machine learning and deep learning

Each project starts from one clear question, uses real public data, and is written so that
anyone can reproduce it.
